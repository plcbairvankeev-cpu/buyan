# Сайт поставщика промышленного и энергетического оборудования

Статический сайт-каталог. Без фреймворков и сборки — открывается двойным кликом по `index.html`.

## Структура

```
index.html         Главная
production.html    Производственное оборудование (приоритет SEO)
batteries.html     Тяговые батареи — сервис (РФ и Монголия)
home-energy.html   Решения для дома
solar.html         Солнечные станции
ev.html            Электромобили
tenders.html       Заказчикам: 44-ФЗ и 223-ФЗ + реквизиты
about.html         О компании
contacts.html      Контакты + форма запроса
cn.html            Китайская посадочная (отдельная, не перевод всего сайта)
privacy.html       Политика конфиденциальности (заготовка, проверить у юриста)
consent.html       Согласие на обработку данных 152-ФЗ (заготовка)
assets/
  css/styles.css   Вся вёрстка и дизайн-система (цвета — в :root вверху файла)
  js/config.js     ВСЕ изменяемые значения: название, реквизиты, факты, контакты
  js/main.js       Подстановка config, мобильное меню, заглушка форм
```

## Что заполнить перед запуском

1. **Название компании.** В `assets/js/config.js` → `company.name` и `company.legalName`.
   Плюс find-and-replace по строке `«название»` в HTML (в `<title>`, JSON-LD и статических подписях,
   куда JS не подставляет). В `cn.html` название — в форме `「название」`.
2. **Реквизиты и контакты.** Всё в `config.js` — сейчас прочерки `—`. Заполнить после регистрации ООО.
3. **Цифры в полосе фактов.** `config.js` → `facts.*` (сейчас условные).
4. **Формы.** Отправки нет. Укажите `form.endpoint` в `config.js` и раскомментируйте `fetch`-блок
   в `assets/js/main.js` (помечен комментарием).
5. **Файлы-заглушки** (на них есть ссылки, но самих файлов нет — добавьте):
   - `assets/catalog.pdf` — каталог оборудования;
   - `assets/company-card.pdf` — карточка предприятия.
6. **Юридические тексты.** `privacy.html` и `consent.html` — заготовки, согласовать с юристом.
7. **Фото оборудования.** В блоке «Ключевое направление» на главной сейчас SVG-заглушка
   (`index.html`, `.dir-featured__media`) — заменить на `<img>` с фотографией.

## Технические заметки

- Адаптив до 360 px, видимый фокус на клавиатуре, учтён `prefers-reduced-motion`.
- Микроразметка Organization (JSON-LD) — в `index.html`, заполнить URL и реквизиты.
- `title` и `description` заданы на каждой странице.
- Шрифты системные — сайт не тянет внешние ресурсы и работает офлайн.
- Чистые URL (`/production` вместо `/production.html`) можно настроить на хостинге;
  локально и по умолчанию ссылки ведут на `.html`, чтобы работал двойной клик.
